# Grupo2-Mon-Santucho-Bit-cora-4to4ta-2026

El dia de hoy estuvimos charlando con mi grupo (Benitez, Cabral, Ojeda y Pereira) sobre qué proyecto vamos a realizar.
Tuvimos en mente estos dos proyectos: el sensor de humo y gas o estación meteorológica.
Luego de estar pensando un rato, terminamos eligiendo la opción de estación meteorológica porque al menos sabemos más o menos por donde podemos empezar.
La estación meteológica trata de un instrumento diseñados para poder medir, registrar y analizar cambios atmosféricas como temperatura, humedad, viento, presión y precipitaciones.
Al final, solo podrá medir temperatura y humedad.
